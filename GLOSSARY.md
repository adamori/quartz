## Conventions
- One markdown file per PDF page: `manual/page-NN.md`.
- Each file starts with a running header line (section · model) and the printed page number.
- Tables are rebuilt as markdown tables.
- Labelled diagrams: the figure is described in a `> [Figure: ...]` note, and every
  numbered callout is translated as a numbered legend list.
- Safety boxes use blockquotes: `> ⚠️ **WARNING**`, `> ❗ **CAUTION**`, `> ℹ️ **NOTE**`.
- Units, model names (Quartz / Quartz M), and brand (DERUIZ) are kept verbatim.
