# DERUIZ Quartz & Quartz M — Operating Manual (English translation)

A page-by-page **English translation** of the German operating manual
*"Bedienungsanleitung Quartz & Quartz M"* (DERUIZ e-bike, 65 pages).

Each PDF page is reconstructed by hand as its own markdown file under
[`manual/`](manual/), so that tables, spec sheets, error-code lists and labelled
diagrams stay readable — something automated PDF-to-text extraction mangles.
Terminology is kept consistent via [`GLOSSARY.md`](GLOSSARY.md).

## How to read

Start with the translated [Table of Contents](manual/page-03.md), or open pages
directly:

- `manual/page-01.md` … `manual/page-65.md` — one file per PDF page.
- The running header in each file shows the section and model.
- Figures/diagrams are described in `> [Figure: …]` notes with every callout label
  translated; full-page tables are rebuilt as markdown tables.

## Source

- Source document: *Bedienungsanleitung Quartz & Quartz M* (rev. 3.20.26), 65 pages,
  A5 landscape, German.
- Translation method: vision-based human reconstruction (not machine OCR).
