# Display Readout

> [Figure: Diagram of the display screen with numbered callouts. Across the top: a Bluetooth symbol (1), a lighting/headlight symbol (2) and a four-segment battery charge indicator with percentage readout (3). In the centre, a large two-digit speed readout with "mph" and "km/h" units (5), and a boxed single-digit field at lower right for the assist level / error code (4, 6). ## Indicators

1. Bluetooth
2. Lighting
3. Battery charge indicator
4. Assist level
   0, 1, 2, 3, 4, 5, P (walk assist)
5. Speed (mph / km/h)
6. Error code display (flashes)
7. Ride data
   - **TRIP** (trip distance)
   - **ODO** (total distance)
   - **MAX**
   - **POWER**
