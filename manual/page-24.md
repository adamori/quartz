# Error display on the display

If a fault is present, the error symbol lights up on the display and the current speed is shown as an error code.

| Error code | Malfunction / Description |
|---|---|
| **E30** | Communication failure. The unit cannot receive any data from the controller, or the received data is faulty. <br>1. Check whether the CANL and CANH communication lines are connected correctly. <br>2. Check whether the wiring harness and the connector are loose or defective. <br>3. Check whether the communication protocols of the display match. |

> ❗ **CAUTION**
>
> If an error code is displayed, please contact a Deruiz service partner.
> To return to the normal display, the problem must first be resolved.
> The bicycle cannot be operated beforehand.
